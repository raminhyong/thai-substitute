# ระบบจัดครูสอนแทน กลุ่มสาระการเรียนรู้ภาษาไทย
### โรงเรียนพูลเจริญวิทยาคม

เว็บแอปพลิเคชันสำหรับบริหารจัดการและจัดครูสอนแทน กลุ่มสาระการเรียนรู้ภาษาไทย โรงเรียนพูลเจริญวิทยาคม รองรับการทำงานร่วมกับ Google Apps Script และ Google Sheets

---

## จุดเด่นและฟังก์ชันหลัก

1. **ระบบแนะนำครูสอนแทนอัจฉริยะ (Smart Match)**:
   - ตรวจสอบคาบว่างและตารางสอนของครูในกลุ่มสาระฯ โดยอัตโนมัติ
   - กระจายภาระงานอย่างเป็นธรรมตามสถิติการสอนแทนสะสม
   - ป้องกันการจัดคาบสอนต่อเนื่องเกินภาระที่เหมาะสม

2. **การจัดการประวัติและข้อมูล (Data Management)**:
   - บันทึกและดึงข้อมูลประวัติการสอนแทนผ่าน Google Apps Script / Google Sheets
   - ระบบ Offline Fallback สำรองข้อมูลลง `localStorage` อัตโนมัติเมื่อเครือข่ายขัดข้อง

3. **สรุปรายงานและพิมพ์เอกสารราชการ**:
   - หน้าสรุปการสอนแทนประจำเดือน กรองตามเดือนและปี พ.ศ.
   - ฟอร์มพิมพ์บันทึกข้อความการปฏิบัติหน้าที่สอนแทน พร้อมส่วนลงนามหัวหน้ากลุ่มสาระฯ

4. **ดีไซน์ Luxury Emerald & Gold**:
   - ปรับแต่งให้ทันสมัย สบายตา รองรับทั้งหน้าจอเดสก์ท็อปและสมาร์ตโฟน
   - รองรับ Progressive Web App (PWA) ติดตั้งลงหน้าจอหลักได้ทันที

---

## โครงสร้างโปรเจกต์

- `Index.html` : หน้าเว็บแอปพลิเคชันหลัก (Frontend UI/UX & Client Logic)
- `Code.gs` : โค้ด Google Apps Script Backend สำหรับเชื่อมต่อ Google Sheets API
- `SubstitutionLogs_Thai.html` : ฐานข้อมูลประวัติและเทมเพลตบันทึกการสอนแทน
- `schedule_thai_teachers_2569.json` : ฐานข้อมูลโครงสร้างตารางสอนครูภาษาไทย ปีการศึกษา 2569
- `teachers_db_converted.js` : ข้อมูลครูและตารางสอนในรูปแบบ JavaScript module
- `assets/` : โลโก้, ฟอนต์ราชการ TH Sarabun New, ไอคอน และองค์ประกอบกราฟิก
- `scripts/` : สคริปต์เสริมสำหรับสร้างและประมวลผลไฟล์ภาพแบรนด์

---

## การติดตั้งและใช้งาน

### 1. ใช้งานผ่าน Google Apps Script
1. สร้างโปรเจกต์ใหม่ใน [Google Apps Script](https://script.google.com)
2. นำโค้ดจาก `Code.gs` ไปวางในไฟล์สคริปต์
3. เพิ่มไฟล์ HTML และนำโค้ดจาก `Index.html` ไปวาง
4. เผยแพร่เป็น **Web App** (ตั้งค่า Execute as: Me, Who has access: Anyone)

### 2. ใช้งานแบบ Local หรือ Static Hosting
- สามารถเปิดไฟล์ `Index.html` ผ่านเว็บเบราว์เซอร์ หรือรัน Local Web Server (เช่น Live Server, Python http.server) ได้ทันที
